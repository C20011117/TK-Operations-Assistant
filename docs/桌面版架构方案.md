# 桌面版架构方案：单机 Windows 安装包（Tauri）

版本：1.0 · 日期：2026-09-29 · 状态：已确认，实施中

## 0. 这份文档改变了什么

产品交付形态从“本地网页 + 服务器”改为**安装在 Windows 电脑上、双击即用的桌面应用（.exe 安装包）**。2026-09-29 与用户确认：

| 事项 | 决定 |
|---|---|
| 使用方式 | **单机独立使用**：每台电脑装一份，数据只保存在本机，不需要服务器；不同 BD 之间不共享数据 |
| 运行依赖 | **双击即用**：不要求安装 Docker、Python、Node 或数据库 |
| 桌面外壳 | **Tauri 2** |
| 支持系统 | **仅 Windows**（Windows 10 22H2 及以上、Windows 11，x64） |

优先级：本文件与 [纵向切片方案](纵向切片方案.md) 或 `docs/architecture/` 中面向“多企业服务器部署”的设计冲突时，**以本文件为准**。产品功能范围、业务流程和数据质量规则不变，改变的是运行形态和随之调整的技术选型。

## 1. 架构总览

```text
┌──────────────── TK 达人工作台.exe（Tauri 2 外壳，Rust） ────────────────┐
│  WebView2 窗口：React + TypeScript 界面（沿用现有前端代码）               │
│        │  HTTP  127.0.0.1:<随机端口>，每次启动生成的随机令牌              │
│        ▼                                                                   │
│  后端进程 tk-backend.exe（Python 3.12，PyInstaller 打包）                  │
│    FastAPI 接口 · 业务模块 · 进程内任务执行器 · LangGraph                  │
│    FastMoss MCP 客户端 · 大模型网关（OpenAI 兼容）                         │
│        │                                                                   │
│        ├─ SQLite 数据库       %LOCALAPPDATA%\TKWorkspace\data\app.db      │
│        ├─ 本地文件            %LOCALAPPDATA%\TKWorkspace\files\           │
│        ├─ 日志                %LOCALAPPDATA%\TKWorkspace\logs\            │
│        └─ 密钥                Windows 凭据管理器（keyring / DPAPI）        │
└────────────────────────────────────────────────────────────────────────────┘
        │ HTTPS（仅在调用时联网）
        ├─ FastMoss MCP  https://mcp.fastmoss.com/mcp
        └─ 大模型服务（OpenAI 兼容接口）
```

选择“Tauri 外壳 + Python 后端子进程”的原因：已写好的 React 界面和 Python 业务代码（FastMoss 客户端、LangChain / LangGraph、任务执行器）可以直接复用；Rust 只负责窗口、启动和关闭后端、单实例，代码量很小。

## 2. 组件替换对照

| 服务器版（M0 已实现） | 桌面版 | 说明 |
|---|---|---|
| PostgreSQL 18 + pgvector（Docker） | **SQLite**（WAL 模式，随应用内置） | 零安装。以后做 RAG 时用 `sqlite-vec` 扩展存向量 |
| Redis + Celery Worker + Outbox 分发器 | **进程内任务执行器** | 仍使用 `jobs` 表、租约和 fencing，崩溃或关闭后重启可恢复；不再需要消息队列 |
| MinIO 对象存储 | **本地文件目录** | 按 SHA-256 去重；视频通过带签名的短时链接播放 |
| 登录、会话 Cookie、CSRF | **不需要登录**；本机接口用启动令牌保护 | 见第 4 节。以后可加“启动密码”锁定应用 |
| 多企业 `tenant_id` + PostgreSQL RLS | **去掉** | 单机单用户，数据隔离由 Windows 用户账户和文件权限保证 |
| `.env` 保存密钥 | **Windows 凭据管理器** | FastMoss Key、大模型 Key 在“设置”页面填写，不写入任何文件 |
| Docker Compose、CI 中的数据库服务 | **去掉** | 测试直接用临时 SQLite，更快 |
| LangGraph checkpoint（PostgreSQL） | `langgraph-checkpoint-sqlite` | 同一个数据库文件 |
| Vite 开发服务器代理 `/api` | 前端从外壳获取端口和令牌后直接请求 | 开发时仍可用浏览器调试，见第 7 节 |

**保留不变**：业务模块划分、版本化与不可变快照、三态硬条件、幂等键、对外动作本人确认、金额与币种、UTC 时间 + IANA 时区、`markets` 市场目录、FastMoss 连接器注册表与费用记账、OpenAPI 生成前端类型。

## 3. 数据存储

- **位置**：`%LOCALAPPDATA%\TKWorkspace\`（例：`C:\Users\<用户>\AppData\Local\TKWorkspace\`）。只有当前 Windows 用户可读写。
  - `data\app.db`：SQLite 主库（WAL 模式、`foreign_keys=ON`、`busy_timeout=5000`）
  - `files\`：视频、附件，文件名为 SHA-256
  - `logs\`：滚动日志（单文件 10 MB × 5 份），写入前去除密钥和个人数据
  - `backups\`：自动备份（见下）
- **迁移**：继续用 Alembic（SQLite 批量模式 `render_as_batch=True`）。应用启动时先自动备份，再执行迁移；迁移失败则还原备份并提示，不带着半升级的数据库运行。
- **金额**：SQLite 没有精确小数类型，金额统一存为**十进制字符串**（自定义 SQLAlchemy 类型，读写都是 `Decimal`），并与币种字段同表，禁止用浮点数存金额。
- **时间**：统一存 UTC ISO 8601 文本；显示时按站点或用户时区转换。
- **JSON 字段**：SQLite `JSON`（文本），读写经 Pydantic 校验。
- **备份**：每天首次启动和每次迁移前，用 SQLite 在线备份接口写入 `backups\`，保留最近 7 份；设置页面提供“导出备份 / 从备份恢复”。
- **卸载**：默认保留用户数据（重装后可继续使用）；卸载程序提供“同时删除所有数据”的勾选项。

## 4. 本机安全

本地 HTTP 接口虽然只监听 `127.0.0.1`，但本机其他程序和浏览器里的网页仍可能访问它，所以必须保护：

1. **随机端口**：后端启动时绑定 `127.0.0.1:0`，由系统分配空闲端口，并通过标准输出告诉外壳。
2. **启动令牌**：外壳每次启动生成 32 字节随机令牌，通过环境变量传给后端；所有接口都必须带 `Authorization: Bearer <令牌>`，否则返回 401。令牌只在内存中，不落盘。
3. **Host 检查**：只接受 `Host: 127.0.0.1:<端口>`，防止 DNS 重绑定攻击。
4. **CORS**：只允许 Tauri 窗口的来源（Windows 下为 `http://tauri.localhost`），开发模式额外允许 `http://localhost:5173`。
5. **视频等媒体**：`<video>` 标签无法附带请求头，所以用 HMAC 签名、60 秒内有效的一次性链接。
6. **密钥**：FastMoss Key、大模型 Key 存 Windows 凭据管理器（`keyring` 库，底层 DPAPI），数据库和日志中只保存“是否已配置”和末 4 位。
7. **个人数据加密**：寄样地址等个人数据字段使用 AES-GCM 加密，数据密钥同样保存在凭据管理器；数据库文件被单独拷走也无法读出这些字段。
8. **后端随外壳退出**：外壳关闭时结束后端；外壳异常崩溃时，后端每 2 秒检查父进程，父进程不存在即自行退出，不留孤儿进程。
9. **单实例**：再次双击时激活已打开的窗口，不启动第二个后端（避免两个进程同时写一个数据库）。

## 5. 后台任务（进程内）

- 仍然是“先写 `jobs` 表，再执行”：接口在一个事务里创建任务（含幂等键）并返回 202，执行器轮询领取。
- 执行器在后端进程内运行：I/O 型任务（FastMoss、大模型）用 asyncio，默认同时 2 个任务；CPU 型任务放线程池。
- 保留租约和 fencing：应用被强制关闭后再启动时，租约过期的 `running` 任务按任务类型的规则重新排队或标记失败，并写明原因。对外动作（如寄样登记）绝不自动重试。
- FastMoss 限流（试用 / Basic 每分钟 40 次）改为进程内令牌桶。
- 任务状态变化通过轮询接口获取（1 秒）；以后可改为 Server-Sent Events。

## 6. 安装包与发布

- **打包流程**：
  1. `pnpm build` 生成前端静态文件，由 Tauri 内嵌。
  2. PyInstaller 以**目录模式（onedir）**打包后端为 `tk-backend\tk-backend.exe`。不用单文件模式：单文件每次启动都要解压到临时目录，启动慢且更容易被杀毒软件误报。
  3. `tauri build` 把后端目录作为资源打入，生成 **NSIS 安装包** `TK达人工作台_<版本>_x64-setup.exe`。
- **安装方式**：按当前用户安装（不需要管理员权限），开始菜单与桌面快捷方式。WebView2：Windows 11 和已更新的 Windows 10 自带；安装包内置 WebView2 引导程序，缺失时自动安装。
- **体积预估**：安装包约 60–90 MB（主要是 Python 运行时和依赖），安装后约 200–300 MB。
- **启动时间目标**：冷启动到界面可用 ≤ 5 秒（期间显示启动画面）。
- **代码签名**：未签名的安装包会触发 Windows SmartScreen“未知发布者”提示。内部试用阶段可接受；正式分发前需要购买代码签名证书（见第 10 节）。
- **自动更新**：切片阶段手动下载新版覆盖安装；以后接入 `tauri-plugin-updater`（需要签名和发布地址）。
- **版本号**：外壳、后端、前端共用一个版本号，界面“关于”页显示，日志中记录。

## 7. 开发方式

| 场景 | 做法 |
|---|---|
| 日常开发 | `pnpm tauri dev`：启动 Vite 和 Tauri 窗口；调试构建下外壳用 `uv run` 启动后端源码，前端改动热更新 |
| 只改后端 | `uv run python -m tk_workspace.desktop --dev`：固定端口 8765、开发令牌，可用浏览器打开 `http://localhost:5173` 调试 |
| 测试 | `uv run pytest`：每个测试用临时目录和临时 SQLite，无需任何外部服务 |
| 打安装包 | `scripts/build-desktop.ps1`：依次构建前端、PyInstaller 后端、Tauri 安装包 |

开发机需要：Rust（stable，MSVC 工具链）、Visual Studio 生成工具（C++）、Python 3.12 + uv、Node 24 + pnpm。**用户电脑不需要其中任何一项。**

## 9. 对里程碑的影响

M0（服务器版地基）的功能已完成并通过验收，其中可复用的部分迁移到桌面版。新增 **M0-D 桌面地基**，完成后再继续 M1–M5，M1–M5 的业务内容与完成标准不变（去掉其中与登录、多企业隔离相关的条款）。

| 里程碑 | 内容 | 完成标准 |
|---|---|---|
| **M0-D 桌面地基** | Tauri 外壳 + 后端子进程、SQLite + Alembic（含欧洲 11 站）、进程内任务执行器、设置页（凭据管理器保存 Key）、FastMoss / 大模型连通检查、本机接口保护、NSIS 安装包、CI（测试 + Windows 安装包构建） | ① 在未安装 Python / Node / Docker 的 Windows 上安装后双击可用；② 冷启动 ≤ 5 秒；③ 空任务执行完成，强制结束进程后重启，中断的任务被正确恢复或标记；④ 不带令牌访问本机接口返回 401；⑤ 数据目录和日志中搜不到 Key 明文；⑥ FastMoss 连通检查不扣额度，大模型连通检查通过；⑦ 关闭窗口后无残留后端进程 |
| M1–M5 | 同 [纵向切片方案](纵向切片方案.md) 第 8 节 | 同上（删除“两个 BD 互相看不到数据”等多用户条款） |

## 10. 风险与待确认

| 事项 | 当前处理 | 影响 |
|---|---|---|
| 代码签名证书 | 内部试用先不签名 | 正式分发时 SmartScreen 提示、部分杀毒软件误报；证书年费约 100–400 美元（OV/EV 不同） |
| 杀毒软件误报 PyInstaller 程序 | 使用 onedir、不加壳、签名后提交误报申诉 | 安装或启动被拦截 |
| FastMoss 条款：数据保密、不得分享 | 单机使用、数据不出本机（除调用大模型时发送必要字段） | 比多企业服务器版更容易合规；导出功能需提示“仅限内部使用” |
| 多台电脑之间的数据迁移 | 通过“导出备份 / 恢复”手动迁移 | 不支持多台电脑同时使用同一份数据 |
| 本机数据丢失（硬盘损坏、重装系统） | 自动备份在本机；提示用户定期导出到其他位置 | 建议开启 BitLocker 并外部备份 |
| 大模型的数据处理地区（GDPR） | 设置页记录服务商和地区 | 发送给模型的达人数据需最小化 |
| 开发机磁盘空间（C 盘剩约 10 GB） | Rust 与构建缓存放 D 盘 | 构建目录约 3–5 GB |
